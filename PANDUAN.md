# Panduan publikasi website

## A. Membuka rancangan
1. Ekstrak ZIP.
2. Buka `index.html` di browser untuk melihat prototipe.
3. Ganti nama brand, tulisan, alamat email, foto, dan informasi layanan sesuai usaha Anda.

## B. Memasang di GitHub Pages
1. Masuk ke GitHub dan buat repository baru, misalnya `jelajah-jogja`.
2. Unggah `index.html` ke root repository. Sertakan `README.md` jika diperlukan.
3. Buka **Settings → Pages**.
4. Pada bagian build/deployment, pilih **Deploy from a branch**, pilih branch `main` dan folder `/(root)`, lalu simpan.
5. Tunggu proses deployment selesai; GitHub akan menampilkan alamat website Pages di halaman tersebut.

## C. Menggunakan Google Sites
Google Sites tidak mengimpor satu paket HTML/CSS/JavaScript sebagai situs editable secara langsung. Gunakan rancangan ini sebagai acuan desain dan salin konten ke Google Sites:
1. Buka Google Sites dan buat situs kosong.
2. Buat halaman/section: Beranda, Sejarah Yogyakarta, Makanan Khas, dan Pariwisata.
3. Buat banner beranda dengan foto Yogyakarta dan judul brand.
4. Buat tiga kartu/menu yang mengarah ke bagian/halaman terkait.
5. Tambahkan foto, nama, dan deskripsi makanan/destinasi dari rancangan ini.
6. Unggah gambar ke Google Drive atau gunakan foto berlisensi, lalu sisipkan lewat **Insert → Images**.
7. Untuk menampilkan versi GitHub Pages, gunakan **Insert → Embed → By URL** jika Google Sites menerima URL tersebut; jika tidak, tambahkan tombol/link yang membuka situs GitHub Pages di tab baru.
8. Klik **Publish** setelah memeriksa tampilan desktop dan ponsel.

## D. Sebelum dipublikasikan
- Ganti alamat email contoh `.example` dengan kontak bisnis yang aktif.
- Gunakan foto milik sendiri atau foto yang lisensinya mengizinkan penggunaan komersial.
- Verifikasi sejarah, lokasi, jam buka, harga, dan akses setiap destinasi.
- Tambahkan nama usaha, nomor WhatsApp, paket wisata, kebijakan pembatalan, dan informasi legal yang dibutuhkan.
